小火箭配置与模块安装

用 Safari 打开本页，点击安装按钮。如果出现“在 Shadowrocket 中打开”，请选择打开。无需在模块页面找扫码入口。

直连配置 · OpenAI · Twitter / X · Telegram · Google

① 导入直连基础配置

使用 direct.conf，让未被模块匹配的请求直连。

导入 direct.conf

小火箭 → 配置页面右上角＋ → 粘贴 URL → 下载 → 点击 direct.conf → 使用配置。

② 安装 OpenAI 分流模块

匹配 ChatGPT / OpenAI 及上游规则中的依赖域名，使用当前代理节点。

安装 OpenAI 模块

小火箭 → 配置 → 模块 → 右上角＋ → 粘贴 URL → 下载并启用。模块添加页面只有 URL 入口，不需要扫码。

③ 安装 Twitter / X 分流模块

匹配 Twitter / X、短链接、图片等相关请求，使用当前代理节点。上游规则也包含 grok.com。

安装 Twitter / X 模块

小火箭 → 配置 → 模块 → 右上角＋ → 粘贴 URL → 下载并启用。已使用 direct.conf 时无需重复导入配置；可与 OpenAI 模块同时启用。

④ 安装 Telegram 分流模块

匹配 Telegram 域名、数据中心 IP 和 ASN 等相关请求，使用当前代理节点。

安装 Telegram 模块

下载后启用 Telegram 分流，保持全局路由为「配置」。已使用 direct.conf 时无需重复导入配置。通话还取决于节点的 UDP 能力及 Telegram 的通话设置。

⑤ 安装 Google 分流模块

匹配 Google 搜索、Gmail、Drive 及上游规则中的其他服务，使用当前代理节点。

安装 Google 模块

Google 模块不包含 YouTube 专属规则。广告、统计、公共资源和部分国内可访问的 Google 域名也可能走代理。已使用 direct.conf 时无需重复导入配置。

⑥ 连接并验证

  1. 当前配置选择 direct.conf，按需要启用 OpenAI、Twitter / X、Telegram、Google 分流模块，可以同时启用。
  2. 首页全局路由选择配置，选中可用代理节点并连接。
  3. 在“测试规则”检查已启用服务对应的域名（chatgpt.com、x.com、telegram.org 或 google.com）→ PROXY，baidu.com → DIRECT，再打开相应服务实测。

无需安装证书。若此前装过 Direct.conf，请用本页的小写 direct.conf 下载地址重新添加。其他分流模块也会影响请求策略。
