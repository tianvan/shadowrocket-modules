小火箭配置与模块安装

用 Safari 打开本页，点击安装按钮。如果出现“在 Shadowrocket 中打开”，请选择打开。无需在模块页面找扫码入口。

① 导入直连基础配置

使用 direct.conf，让未被模块匹配的请求直连。

导入 direct.conf

小火箭 → 配置页面右上角＋ → 粘贴 URL → 下载 → 点击 direct.conf → 使用配置。

② 安装 OpenAI 分流模块

匹配 ChatGPT / OpenAI 及上游规则中的依赖域名，使用当前代理节点。

安装 OpenAI 模块

小火箭 → 配置 → 模块 → 右上角＋ → 粘贴 URL → 下载并启用。模块添加页面只有 URL 入口，不需要扫码。

③ 连接并验证

  1. 当前配置选择 direct.conf，只启用 ChatGPT / OpenAI 分流模块。
  2. 首页全局路由选择配置，选中可用代理节点并连接。
  3. 在“测试规则”检查 chatgpt.com → PROXY，baidu.com → DIRECT，再打开 ChatGPT 实测。

无需安装证书。若此前装过 Direct.conf，请用本页的小写 direct.conf 下载地址重新添加。其他分流模块也会影响请求策略。
